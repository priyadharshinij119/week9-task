## Analysis of Sales Trends

### 2. Increasing and Decreasing Trends

The Line Graph shows an overall fluctuating but upward sales pattern over the dataset period.

Sales do not increase continuously every month. Instead, the graph contains several increases and decreases. However, sales generally become stronger during the later months of each year.

### 3. Sudden Peaks and Drops

The Line Graph contains several noticeable peaks and drops.
